# Security Policy

## Supported Versions

Currently, only the `main` branch (latest release) is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in JobTrail, please report it to us by emailing **vallabhpatil5347@gmail.com**.

We will acknowledge your email within 48 hours, and provide a timeline for triage and resolution.
